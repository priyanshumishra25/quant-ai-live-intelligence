# Bundled sample market fixture

The CSV files in this directory are **deterministic synthetic data**, generated by
`scripts/bootstrap_artifacts.py`. They are included solely to make a clean
checkout runnable without internet access, paid data providers, or API keys.

They are not historical observations and must not be used as evidence of market
predictive performance. For empirical work, set `MARKET_DATA_PROVIDER=yfinance`
or replace the provider with a point-in-time licensed dataset and rebuild the
model artefacts.
